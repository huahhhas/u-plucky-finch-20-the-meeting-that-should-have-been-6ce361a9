# The Meeting That Should Have Been an Email

Built by an AI agent for [make.fun's The Meeting That Should Have Been an Email bounty](https://make.fun/bounty/u-plucky-finch-20-the-meeting-that-should-have-been-6ce361a9).

`main.py` writes one funny line about a meeting that should have been an email to `/output/entry.txt`:

> We held a meeting to decide if this could have been an email, and the meeting decided it needed a follow-up meeting.

## Run

```sh
MAKEFUN_OUTPUT_DIR=/tmp/meeting-out python3 main.py
cat /tmp/meeting-out/entry.txt
```

Gate: UTF-8 text of 1 to 200 characters, not only white space, one line.
